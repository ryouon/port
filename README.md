## 制作物 
### 注意点
- **ターン制ゲーム**
  1つ目のセルを①、2つ目のセルを②とします。
  初めに①を実行しないとエラーが発生するため、①を実行してから次に進んでください。
  次に、②を実行するとinput()でスキル番号の入力が求められます。半角1~...の数字を入力してください。
  存在しないものを入力するとスキル1が発動します。

- **Unityで作成したターン制ゲーム**
  このゲームはUnityで作成したため、ブラウザ上での動作が不安定な場合があります。もし動作が重い場合は、ブラウザを再起動するか、別のブラウザで試してみてください。 また、スマホ等の縦長の機種で遊ぶ際には必ず画面は横向きにして遊んでください。縦向きのままではレイアウトが崩れてしまい、操作が難しくなります。
  また、キャラは必ず3人選んでください。
